TaskFlow Pro
A premium MERN Stack Task Management Web Application built with React, Node.js, Express.js, and MongoDB.

Features:
* User Authentication using JWT
* Register & Login System
* Create, Edit, Delete Tasks
* Mark Tasks as Completed or Pending
* Search & Filter Tasks
* Premium Glassmorphism UI
* Dark / Light Theme
* Responsive Design
* Protected Routes
* Toast Notifications
* User Settings Page
* Fully Deployed Application

Tech Stack :-
Frontend:
* React.js
* SCSS
* Framer Motion
* React Icons
* Axios
* React Toastify

Backend:
* Node.js
* Express.js
* MongoDB
* JWT Authentication
* Bcrypt.js

Deployment :
Frontend :
Deployed on Vercel

Backend :
Deployed on Render

Installation
Clone Repository :

```bash
git clone https://github.com/Kavinaya-12/taskflow-pro.git
```

### Install Frontend

```bash
cd client
npm install
npm run dev
```

### Install Backend

```bash
cd server
npm install
npm start
```

## Environment Variables

### Server

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
PORT=5000
```
